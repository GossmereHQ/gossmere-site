FAQ / NUTRIDATASET

Preguntas para compradores

¿Qué mercados abarca?

La primera versión está dirigida a Estados Unidos, Canadá, Francia y Reino Unido. Se prevén más regiones e idiomas, pero no se presentan como disponibles.

¿Hay una API disponible?

NutriDataset se concibe primero como producto de datos para integración profesional. Recogemos requisitos de API, pero todavía no anunciamos un servicio activo ni una fecha.

¿Puedo revisar una muestra?

Ya puede solicitar una conversación de evaluación. Se ofrecerán muestras validadas y documentación tras las comprobaciones técnicas y de derechos.

¿Con qué frecuencia se actualizará?

Las actualizaciones regulares y trazables son un objetivo. El calendario se concretará con el lanzamiento y el acuerdo comercial.
