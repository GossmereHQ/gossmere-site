Professional access

FAQ / NUTRIDATASET

Questions buyers ask

Which markets are covered?

The first release targets the United States, Canada, France and the United Kingdom. Further geographic and language expansion is planned; no additional country is presented as released.

Is an API already available?

NutriDataset is being designed first as a data product for professional integration. We are gathering API requirements, but no live API service or launch date is announced.

Can I review a sample?

You can request an early evaluation discussion now. A validated data sample and technical pack will be offered when release and permission checks allow.

How often is it updated?

Regular, traceable updates are a design objective. The exact service cadence will be specified with the release and commercial agreement.
